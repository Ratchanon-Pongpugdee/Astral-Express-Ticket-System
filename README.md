# INTERSTELLAR EXPRESS SKYTRAIN

ระบบจำหน่ายตั๋วรถไฟอวกาศแบบ Command Line Interface (CLI) พัฒนาด้วยภาษา Python
สำหรับจำลองการเลือกสถานี คำนวณราคาตั๋ว รับเงิน ทอนเงิน และบันทึกข้อมูลการเดินทาง

## Properties

- แสดงรายชื่อสถานีปลายทางและราคาประจำสถานี
- เลือกสถานีต้นทางและสถานีปลายทางเพื่อคำนวณราคาตั๋ว
- รองรับเงินที่เครื่องรับ ได้แก่ `1, 2, 5, 10, 20, 50, 100, 500, 1000`
- คำนวณและจ่ายเงินทอนโดยเลือกใช้เงินจากจำนวนที่มีอยู่ในระบบ
- แสดงรายละเอียดตั๋วและเงินทอนหลังทำรายการสำเร็จ
- บันทึกจำนวนผู้โดยสารขาเข้าและขาออกของแต่ละสถานี
- บันทึกข้อมูลกระเป๋าเงินและสถานีกลับลงไฟล์อัตโนมัติหลังขายตั๋ว
- มีเมนู Maintenance สำหรับแก้ไขข้อมูลสถานีและจำนวนเงินในเครื่อง
- ตรวจสอบสต็อกเงินและแจ้งรายละเอียดเมื่อมีเงินทอนไม่เพียงพอ

## Requirements

- Python 3.10 ขึ้นไป
- ระบบปฏิบัติการที่สามารถรัน Python ได้ เช่น Windows, macOS หรือ Linux
- โปรแกรมใช้เฉพาะไลบรารีมาตรฐานของ Python เช่น Spyder ต้องติดตั้ง Extensions เพิ่มเติม

## Guides

เมื่อเริ่มโปรแกรม จะพบเมนูหลักดังนี้:

| ตัวเลือก | รายละเอียด                                     |
| -------- | ---------------------------------------------- |
| `b`      | ซื้อบัตรโดยเลือกสถานีต้นทาง ปลายทาง และใส่เงิน |
| `m`      | เข้าสู่เมนู Maintenance สำหรับผู้ดูแลระบบ      |
| `s`      | ปิดการทำงานของเครื่อง                          |

ระหว่างการซื้อบัตร ผู้ใช้สามารถพิมพ์ `c` เพื่อยกเลิกขั้นตอนปัจจุบันและรับเงินที่ใส่ไปคืน

### Maintenance

เมนู Maintenance และ Shutdown ต้องใช้รหัสผ่าน:

```text
Manop
```

ภายในเมนูนี้มีตัวเลือก:

- `g` แก้ไขชื่อและราคาสถานี รวมถึงเลือกรีเซ็ตจำนวนผู้โดยสาร
- `w` แก้ไขชื่อ มูลค่า และจำนวนเงินในกระเป๋าเงินของเครื่อง
- `c` ออกจากเมนู Maintenance

> รหัสผ่านนี้ถูกกำหนดไว้ในซอร์สโค้ด เหมาะสำหรับการสาธิตหรือการเรียนรู้เท่านั้น

## Data Files

| ไฟล์                  | หน้าที่                             |
| --------------------- | ----------------------------------- |
| `G04_TermProject.py`  | ซอร์สโค้ดหลักของระบบ                |
| `G04_termProject.bat` | สคริปต์สำหรับรันโปรแกรมบน Windows   |
| `Stations.txt`        | รายชื่อสถานี ราคา และสถิติผู้โดยสาร |
| `Wallet.txt`          | ชนิดเงิน มูลค่า จำนวนเงิน และยอดรวม |

โปรแกรมจะอ่านไฟล์ `Stations.txt` และ `Wallet.txt` จากโฟลเดอร์ปัจจุบันเมื่อเริ่มทำงาน
และเขียนข้อมูลที่เปลี่ยนแปลงกลับลงไฟล์เดิมหลังรายการสำเร็จ

## Limitations in Beta Version

- เป็นโปรแกรมแบบข้อความ ยังไม่มีส่วนติดต่อผู้ใช้แบบกราฟิก
- ไฟล์ข้อความต้องอยู่ในโฟลเดอร์เดียวกับซอร์สโค้ดและรันโปรแกรม
- รองรับการใช้งานทีละรายการผ่านเครื่องเดียว
- การตั้งค่าบางส่วน เช่น รหัสผ่านและชนิดเงินที่รับ ถูกกำหนดไว้ในซอร์สโค้ด
